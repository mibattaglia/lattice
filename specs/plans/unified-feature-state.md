# Unified Feature State

Status: ⬜ Planned — breaking change (next major). Supersedes the `DomainState`/`ViewState` split
described in [view-model.md](../view-model.md), [view-state-reducer.md](../view-state-reducer.md)
and the `@ObservableState`/`@ViewStateReducer` sections of [macros.md](../macros.md).

Every contract in this document was compiled against Swift 6.4 (Xcode 26.4, Swift 6 language
mode) in standalone spikes before being written down; see [§11](#11-references).

## 1. Summary

A feature has one `State`. The `Interactor` is its only mutator. Views read state through a
macro-generated `ViewState` projection that omits `@Domain` members at compile time while keeping
every member observation-tracked, so a visible computed property that depends on a hidden stored
property still re-renders fine-grained.

| Decision | Outcome |
|---|---|
| State model | One `@FeatureState` type per feature; `ViewStateReducer`, `BuildViewState`, `ViewStateReducerBuilder`, `DefaultValueProvider`, `@ViewStateReducer`, `@ObservableState` are removed. |
| Hiding | `@Domain var x` hides a property from views; visible by default. |
| Nesting | No annotation. The compiler classifies members (leaf / child state / optional child / collection of children) through overload resolution of `Lattice._$project(_:)`. |
| Coarse read | `viewModel.viewState` / `scoped.viewState` return `State.ViewState` (the generated projection). |
| `Feature` | Kept: `Feature<Action, State>` bundles the interactor and an optional `areStatesEqual`. |
| Equality | `State: Equatable` is not required. When available, `areStatesEqual` gates content-equal wholesale root replacement and drives `TestViewModel` diffing. |
| Collections | `Array`, `IdentifiedArrayOf`, any `RandomAccessCollection` of child states; `ForEach` over scoped children. |
| Toolchain | Swift 6.2 tools minimum (`Package@swift-6.2.swift` becomes `Package.swift`). |
| Rename | `Interactor.DomainState` → `Interactor.State`; `@Interactor<State, Action>`. |
| `_state` | `@_spi(Lattice) public` on the projection (protocol requirement). |

## 2. Architecture

```text
View                        viewModel.badge.count                 KeyPath<CounterState.ViewState, Int>
  ViewModel                 access(\.state) on the VM registrar   fires only on wholesale replacement (_$id change)
    CounterState.ViewState(_state)                                struct copy (~30 ns), shares every registrar
      .badge → _$project(_state.badge) → BadgeState.ViewState     tracked getter: access(\.badge)  (coarse: child replaced)
        .count → _$project(_state.count) → Int                     tracked getter: access(\.count) (fine-grained leaf)

sendViewEvent(action)
  var working = _state                       copy shares registrars
  interactor.interact(&working, action)      working.badge.count += 1 → notify(\.count) only, Equatable-gated
  commit(working)                            §5.2: identity-preserving root gate, then store + root fire if _$id changed
  spawnEffects(...)                          unchanged
```

The observation runtime (`ObservationStateRegistrar`, `ObservableStateID`, identity-preserving
`mutate`) is unchanged. The reducer was a separation device, not an observation device; removing it
leaves fine-grained observation intact and moves the view/domain boundary into the type system.

## 3. Runtime contracts

New files under `Sources/Lattice/Observation/` unless noted. Names are final.

### 3.1 `FeatureState` (rename of `ObservableState`)

```swift
import Observation

/// A value type whose observation is tracked per member and whose view-facing surface is
/// `ViewState`. Apply the `@FeatureState` macro; never conform manually.
public protocol FeatureState: Observable {
    /// The macro-generated projection views read through. Omits `@Domain` members.
    associatedtype ViewState: ViewStateProjection where ViewState.State == Self
    var _$id: ObservableStateID { get }
    mutating func _$willModify()
}
```

`ObservableStateID`, `ObservationStateRegistrar`, `_$isIdentityEqual`, `_$willModify` keep their
names; every `any ObservableState` existential becomes `any FeatureState`.

### 3.2 `ViewStateProjection`

```swift
/// The view-facing surface of a `FeatureState`. Generated by `@FeatureState` as a nested type
/// named `ViewState`; a struct for struct states, a mirror enum for enum states.
public protocol ViewStateProjection {
    associatedtype State: FeatureState
    /// The projected state. SPI: Lattice uses it to recover a child for scoping; same-module
    /// code can reach it, other modules only via `@_spi(Lattice) import`.
    @_spi(Lattice) var _state: State { get }
    init(_ state: State)
}

extension ViewStateProjection where State: Identifiable {
    /// Supplies `Identifiable.id` for projections of identifiable states whose `id` is not a
    /// visible member.
    public var id: State.ID { _state.id }
}
```

### 3.3 `ViewStateCollection`

```swift
import IdentifiedCollections

/// A lazily projecting view over a collection of child states. Elements are
/// `Base.Element.ViewState`; indices are the base collection's indices.
public struct ViewStateCollection<Base: RandomAccessCollection>: RandomAccessCollection
where Base.Element: FeatureState {
    @_spi(Lattice) public let _base: Base
    public init(_ base: Base) { _base = base }
    public var startIndex: Base.Index { _base.startIndex }
    public var endIndex: Base.Index { _base.endIndex }
    public func index(after i: Base.Index) -> Base.Index { _base.index(after: i) }
    public func index(before i: Base.Index) -> Base.Index { _base.index(before: i) }
    public subscript(position: Base.Index) -> Base.Element.ViewState { .init(_base[position]) }
}

extension ViewStateCollection {
    /// `IdentifiedArray` lookup. The constraint must name `Element` separately; a
    /// `where Base == IdentifiedArray<ID, Base.Element>` clause is rejected as recursive.
    public subscript<ID: Hashable, Element: FeatureState>(id id: ID) -> Element.ViewState?
    where Base == IdentifiedArray<ID, Element> {
        _base[id: id].map(Element.ViewState.init)
    }
    public var ids: Base.Indices { _base.indices }
}
```

### 3.4 Projection functions (`Sources/Lattice/Observation/Projection.swift`)

Overload resolution of `_$project` *is* the leaf/child classification; the macro never inspects
types. The constrained overloads are preferred whenever they apply.

```swift
@inlinable public func _$project<T>(_ value: T) -> T { value }
public func _$project<T: FeatureState>(_ value: T) -> T.ViewState { .init(value) }
public func _$project<T: FeatureState>(_ value: T?) -> T.ViewState? { value.map(T.ViewState.init) }
public func _$project<C: RandomAccessCollection>(_ value: C) -> ViewStateCollection<C>
where C.Element: FeatureState { .init(value) }

/// Inverse of `_$project`, used by enum mirrors to rebuild `_state`. The explicit target type
/// makes exactly one overload viable even when a payload is itself some `X.ViewState`.
@inlinable public func _$unproject<T>(_ value: T, to _: T.Type) -> T { value }
public func _$unproject<P: ViewStateProjection>(_ value: P, to _: P.State.Type) -> P.State { value._state }
public func _$unproject<P: ViewStateProjection>(_ value: P?, to _: P.State?.Type) -> P.State? { value?._state }
public func _$unproject<C: RandomAccessCollection>(_ value: ViewStateCollection<C>, to _: C.Type) -> C
where C.Element: FeatureState { value._base }

/// Type witness for associated-type inference in generated code. Never executed.
public func _$placeholder<T>(_: T.Type) -> T { fatalError("_$placeholder is a type witness and must not be called") }
```

### 4.1 `@FeatureState` on a struct

Input:

```swift
@FeatureState
public struct CounterState: Equatable, Sendable {
    public var title = "Counter"
    @Domain public var lastUpdatedAt: Date?
    @Domain var nonce = 0
    public var badge = BadgeState()
    public var detail: BadgeState?
    public var rows: IdentifiedArrayOf<BadgeState> = []
    public var tags: [String] = []
    public var lastUpdatedText: String { lastUpdatedAt.map(Self.format) ?? "Never" }
    private var scratch = 0
}
```

Generated members (in addition to today's `_$observationRegistrar`, `_$id`, `_$willModify`,
`shouldNotifyObservers` and the `@ObservationStateTracked` accessors on every stored `var`,
including `@Domain` ones):

```swift
public protocol _$ViewStateTypes {
    associatedtype title
    var _$title: title { get }
    associatedtype nonce               // inferred-type @Domain member: needs a witness for its stub
    var _$nonce: nonce { get }
    associatedtype badge
    var _$badge: badge { get }
    associatedtype detail
    var _$detail: detail { get }
    associatedtype rows
    var _$rows: rows { get }
    associatedtype tags
    var _$tags: tags { get }
    associatedtype lastUpdatedText
    var _$lastUpdatedText: lastUpdatedText { get }
}

public struct _$ViewStateWitness: _$ViewStateTypes {
    public let _$title = Lattice._$project(Lattice._$placeholder(CounterState.self).title)
    public let _$nonce = Lattice._$placeholder(CounterState.self).nonce
    public let _$badge = Lattice._$project(Lattice._$placeholder(CounterState.self).badge)
    public let _$detail = Lattice._$project(Lattice._$placeholder(CounterState.self).detail)
    public let _$rows = Lattice._$project(Lattice._$placeholder(CounterState.self).rows)
    public let _$tags = Lattice._$project(Lattice._$placeholder(CounterState.self).tags)
    public let _$lastUpdatedText = Lattice._$project(Lattice._$placeholder(CounterState.self).lastUpdatedText)
}

@Lattice._IdentifiableIfPossible(CounterState.self)
@Lattice._EquatableIfPossible(CounterState.self)
public struct ViewState: Lattice.ViewStateProjection, Sendable {
    @_spi(Lattice) public let _state: CounterState
    public init(_ state: CounterState) { self._state = state }
    public var title: _$ViewStateWitness.title { Lattice._$project(_state.title) }
    public var badge: _$ViewStateWitness.badge { Lattice._$project(_state.badge) }
    public var detail: _$ViewStateWitness.detail { Lattice._$project(_state.detail) }
    public var rows: _$ViewStateWitness.rows { Lattice._$project(_state.rows) }
    public var tags: _$ViewStateWitness.tags { Lattice._$project(_state.tags) }
    public var lastUpdatedText: _$ViewStateWitness.lastUpdatedText { Lattice._$project(_state.lastUpdatedText) }
    @available(*, unavailable, message: "'lastUpdatedAt' is @Domain state and is not visible to views")
    public var lastUpdatedAt: Date? { fatalError() }
    @available(*, unavailable, message: "'nonce' is @Domain state and is not visible to views")
    public var nonce: _$ViewStateWitness.nonce { fatalError() }
}
```

Generated extension: `extension CounterState: Lattice.FeatureState, Observation.Observable {}`.

Resulting member types: `title: String`, `badge: BadgeState.ViewState`, `detail: BadgeState.ViewState?`,
`rows: ViewStateCollection<IdentifiedArrayOf<BadgeState>>`, `tags: [String]`.

Rules:

| Rule | Why |
|---|---|
| Witness is a `struct` with **instance** `let`s; requirements are instance properties. | A `static let` witness fails in Swift 6 mode for any non-`Sendable` member type ("not concurrency-safe"); `nonisolated(unsafe)` warns on every `Sendable` leaf. |
| Visible member = instance `var`/`let`, stored or computed, not `private`/`fileprivate`, not `static`/`class`, not `@Domain`. `private(set)`/`internal(set)` are visible (check `modifier.detail == nil` before treating `private` as hiding). | Views see what the type's clients see. |
| Property-wrapped members forward `wrappedValue` as a leaf. | Wrapped storage is already excluded from tracking by the memberAttribute role. |
| `@Domain` with an explicit type: stub uses that type. Inferred type: witness entry without `_$project` and stub typed `_$ViewStateWitness.name`. | A `Never`-typed stub masks the message under a contextual type ("cannot convert value of type 'Never'"). |
| Access level of protocol, witness, `ViewState`, its members and `init` mirrors the type's (`public`/`package`/internal). | Required by the compiler for public states. |
| `_state` is always `@_spi(Lattice) public`. | Protocol requirement; `package` is rejected on protocol requirements. |
| `Sendable` on `ViewState` is emitted iff `Sendable` (or `@unchecked Sendable`) appears in the state's inheritance clause. | An overload-selected macro for `Sendable` hits "circular reference … expanding peer macros on 'ViewState'". |
| `Identifiable`/`Equatable` are added by the overloaded extension macros from the state's actual conformances (including conformances declared in other files). `==` compares `_state`. | Type-checked macro arguments resolve the overload. |
| `#if` member blocks are mirrored in all three generated types. | Keeps conditional members conditional. |
| Multi-binding declarations (`var a = 0, b = 0`) expand per binding. | — |

### 4.2 `@FeatureState` on an enum

Input:

```swift
@CasePathable
@FeatureState
enum Phase: Equatable {
    case loading
    case loaded(LoadedState)
    case failed(message: String, retryCount: Int)
    var isBusy: Bool { if case .loading = self { true } else { false } }
    @Domain var retryBudget: Int { 3 }
}
```

Generated (plus today's `_$id`/`_$willModify` switch bodies):

```swift
protocol _$ViewStateTypes {
    associatedtype loaded_0
    var _$loaded_0: loaded_0 { get }
    associatedtype failed_0
    var _$failed_0: failed_0 { get }
    associatedtype failed_1
    var _$failed_1: failed_1 { get }
    associatedtype isBusy
    var _$isBusy: isBusy { get }
}
struct _$ViewStateWitness: _$ViewStateTypes {
    let _$loaded_0 = Lattice._$project(Lattice._$placeholder((LoadedState).self))
    let _$failed_0 = Lattice._$project(Lattice._$placeholder((String).self))
    let _$failed_1 = Lattice._$project(Lattice._$placeholder((Int).self))
    let _$isBusy = Lattice._$project(Lattice._$placeholder(Phase.self).isBusy)
}
@Lattice._IdentifiableIfPossible(Phase.self)
@Lattice._EquatableIfPossible(Phase.self)
@CasePathable                                     // iff the state enum carries @CasePathable
enum ViewState: Lattice.ViewStateProjection {     // `indirect` propagated from the state
    case loading
    case loaded(_$ViewStateWitness.loaded_0)
    case failed(message: _$ViewStateWitness.failed_0, retryCount: _$ViewStateWitness.failed_1)
    init(_ state: Phase) {
        switch state {
        case .loading: self = .loading
        case let .loaded(p0): self = .loaded(Lattice._$project(p0))
        case let .failed(p0, p1): self = .failed(message: Lattice._$project(p0), retryCount: Lattice._$project(p1))
        }
    }
    @_spi(Lattice) var _state: Phase {
        switch self {
        case .loading: return .loading
        case let .loaded(p0): return .loaded(Lattice._$unproject(p0, to: (LoadedState).self))
        case let .failed(p0, p1): return .failed(message: Lattice._$unproject(p0, to: (String).self), retryCount: Lattice._$unproject(p1, to: (Int).self))
        }
    }
    var isBusy: _$ViewStateWitness.isBusy { Lattice._$project(_state.isBusy) }
    @available(*, unavailable, message: "'retryBudget' is @Domain state and is not visible to views")
    var retryBudget: Int { fatalError() }
}
```

Payload types are copied from the `case` syntax (always explicit) and wrapped as `(T).self` so
`T?`/`[T]` sugar parses. Payload-less cases need no witness. Cases inside `#if` are mirrored
under the same clauses. Enum computed properties are forwarded exactly like struct members.

#### Payload kinds

`LoadedState` above is itself `@FeatureState`. The classification is automatic either way —
`_$project` picks the leaf overload for a plain payload — but the two kinds behave differently:

| | `@FeatureState` payload | plain payload (`String`, `Error`, DTO, un-annotated struct) |
|---|---|---|
| Mirror case | `case loaded(LoadedState.ViewState)` | `case loaded(LoadedState)` — exposed raw |
| `@Domain` inside the payload | hidden | not possible |
| Observation while the case is active | fine-grained: a `query` edit fires only `query` observers; the root `_$id` is unchanged | coarse: `_$id(for:)` mints a fresh id per access for non-`FeatureState` payloads, so every content change in the case fires the root and re-renders the whole `switch`; equal-content commits are swallowed by the `areStatesEqual` gate |
| `scopeIfActive(state: \.loaded, action:)` | available (`P: ViewStateProjection`) | not available |
| `$viewModel.loaded.query.sending(...)` | through `LoadedState.ViewState` | through the raw payload |
| `Interactors.When(state: \.loaded, ...)` | unchanged | unchanged |

The coarse path is correct by necessity — a plain payload has no registrars, so a fresh root id is
the only change signal — and is what the Search and Todos examples do today. Convention: a payload
struct the feature owns is `@FeatureState`; primitive and foreign payloads stay plain. The macro
cannot distinguish a forgotten `@FeatureState` from a deliberate leaf without false positives, so
this is documentation, not a diagnostic.

### 4.3 `@Domain`

A no-op peer macro read syntactically by `@FeatureState`. Applies to any instance property
(stored or computed) of a struct or enum state. The property keeps its `@ObservationStateTracked`
accessors.

### 4.4 Diagnostics (errors unless noted)

| Condition | Message |
|---|---|
| Applied to a class or actor | `'@FeatureState' cannot be applied to class type 'X'` (as today) |
| Generic struct/enum (both roles, no further emission) | `'@FeatureState' cannot be applied to generic type 'X': the generated projection uses a nested protocol, which Swift does not allow inside generic types (SE-0404). Make 'X' non-generic or wrap the generic data in a non-generic state type.` |
| `@Domain` on an enum case or a `static` member | `'@Domain' can only be applied to instance properties` |
| `@Domain` on `id` while the inheritance clause lists `Identifiable` | `'id' cannot be '@Domain' on an Identifiable state; its ViewState would not satisfy 'Identifiable'` |
| Existing member or nested type named `ViewState`, `_$ViewStateTypes`, `_$ViewStateWitness`, or a property named `_state` | `'X' is reserved by '@FeatureState'` |
| `@ObservationIgnored`/`@ObservationTracked`/`@PresentationState` used | existing rename fix-its |

### 4.5 `@Interactor<State, Action>`

Generates `typealias State` instead of `typealias DomainState`; everything else is unchanged.

## 5. Interface boundaries

### 5.1 `Feature`

```swift
public protocol FeatureProtocol {
    associatedtype Action: Sendable
    associatedtype State: FeatureState & Sendable
    var interactor: AnyInteractor<State, Action> { get }
    /// Content equality. Gates content-equal wholesale root replacement in `ViewModel` and
    /// drives `TestViewModel` assertions. `nil` when the state has no usable equality.
    var areStatesEqual: ((State, State) -> Bool)? { get }
}

public struct Feature<Action: Sendable, State: FeatureState & Sendable>: FeatureProtocol {
    public let interactor: AnyInteractor<State, Action>
    public let areStatesEqual: ((State, State) -> Bool)?

    public init<I: Interactor & Sendable>(interactor: I, areStatesEqual: ((State, State) -> Bool)?)
    where I.State == State, I.Action == Action {
        self.interactor = interactor.eraseToAnyInteractor()
        self.areStatesEqual = areStatesEqual
    }

    public init<I: Interactor & Sendable>(interactor: I) where I.State == State, I.Action == Action {
        self.init(interactor: interactor, areStatesEqual: nil)
    }
}

extension Feature where State: Equatable {
    public init<I: Interactor & Sendable>(interactor: I) where I.State == State, I.Action == Action {
        self.init(interactor: interactor, areStatesEqual: { $0 == $1 })
    }
}
```

### 5.2 `ViewModel`

Public surface (the action loop, root scopes, `EventTask`, effect spawning are unchanged):

```swift
@MainActor @dynamicMemberLookup
public final class ViewModel<F: FeatureProtocol>: Observable {
    public typealias Action = F.Action
    public typealias State = F.State

    public init(initialState: State, feature: F)

    /// Whole projection. The value itself is coarse: re-renders on wholesale replacement or enum
    /// case change. Members read off it stay fine-grained (the copy shares every registrar), so
    /// `switch viewModel.viewState { case .loaded(let l): Text(l.title) }` re-renders on case
    /// changes and on `title` changes only.
    public var viewState: State.ViewState { State.ViewState(state) }

    /// Member read with fine-grained observation; also registers the root, so struct states never
    /// need `viewState` for observation.
    public subscript<V>(dynamicMember keyPath: KeyPath<State.ViewState, V>) -> V {
        State.ViewState(state)[keyPath: keyPath]
    }

    @discardableResult public func sendViewEvent(_ event: Action) -> EventTask

    /// Raw state. Internal: `TestViewModel`, `ScopedViewModel` and bindings live in this module.
    var state: State {
        _$observationRegistrar.access(self, keyPath: \.state)
        return _state
    }
}
```

Commit path (replaces `commitProductionTransition`; the reducer step and the
`source == .emitted` special case are gone):

```swift
private func commit(_ transition: ActionTransition<State, Action>) {
    let newState = transition.currentState
    let isReplacement = newState._$id != _state._$id
    if isReplacement, let areStatesEqual, areStatesEqual(_state, newState) {
        // Content-equal wholesale replacement: keep the current value so its registrar tree —
        // and every observer registered on it — survives. Nothing changed for the view.
        return
    }
    _state = newState
    if isReplacement {
        _$observationRegistrar.withMutation(of: self, keyPath: \.state) {}
    }
}
```

Member mutations never go through the stored property's `_modify`: the interactor mutates a
working copy whose registrars are shared with `_state`, so per-member notifications fire during
`interact(state:action:)` and a synchronous observer that re-reads the view model sees the previous
committed value (verified; no exclusivity trap).

### 5.3 `ScopedViewModel`

```swift
@MainActor @dynamicMemberLookup
public struct ScopedViewModel<Child: FeatureState, ChildAction: Sendable> {
    init(state: @escaping @MainActor () -> Child, send: @escaping @MainActor (ChildAction) -> EventTask)

    public var viewState: Child.ViewState { Child.ViewState(_state()) }               // coarse value; members read off it are fine-grained
    public subscript<V>(dynamicMember keyPath: KeyPath<Child.ViewState, V>) -> V       // fine-grained
    @discardableResult public func sendViewEvent(_ action: ChildAction) -> EventTask
    public func binding<V>(_ keyPath: KeyPath<Child.ViewState, V>, sending embed: CaseKeyPath<ChildAction, V>) -> Binding<V>
}

/// Lets `ForEach(viewModel.scope(state: \.rows, action: \.row))` identify rows.
extension ScopedViewModel: @MainActor Identifiable where Child: Identifiable {
    public var id: Child.ID { _state().id }
}
```

The state closure always reads live from the parent. A captured value would still be notified
(shared registrar) but would serve stale data.

Scoping overloads exist identically on `ViewModel` (over `State.ViewState`) and on
`ScopedViewModel` (over `Child.ViewState`). `Child` is recovered as `P.State`; `\.badge` infers
without annotation.

```swift
extension ViewModel where Action: CasePathable {
    public func scope<P: ViewStateProjection, ChildAction>(
        state keyPath: KeyPath<State.ViewState, P>, action embed: CaseKeyPath<Action, ChildAction>
    ) -> ScopedViewModel<P.State, ChildAction> {
        ScopedViewModel(
            state: { [self] in State.ViewState(self.state)[keyPath: keyPath]._state },
            send: { [self] in self.sendViewEvent(embed($0)) }
        )
    }

    /// `nil` while the child is absent. Serves the creation snapshot for the at-most-one
    /// transitional render after removal.
    public func scope<P: ViewStateProjection, ChildAction>(
        state keyPath: KeyPath<State.ViewState, P?>, action embed: CaseKeyPath<Action, ChildAction>
    ) -> ScopedViewModel<P.State, ChildAction>?

    /// One scope per element; each re-finds its element by id on every read (O(n)).
    public func scope<C: RandomAccessCollection, ChildAction>(
        state keyPath: KeyPath<State.ViewState, ViewStateCollection<C>>,
        action embed: CaseKeyPath<Action, (C.Element.ID, ChildAction)>
    ) -> [ScopedViewModel<C.Element, ChildAction>] where C.Element: FeatureState & Identifiable

    /// `IdentifiedArray` specialisation: O(1) lookup via `[id:]`. Preferred by overload ranking.
    public func scope<ID: Hashable, Element: FeatureState & Identifiable, ChildAction>(
        state keyPath: KeyPath<State.ViewState, ViewStateCollection<IdentifiedArray<ID, Element>>>,
        action embed: CaseKeyPath<Action, (ID, ChildAction)>
    ) -> [ScopedViewModel<Element, ChildAction>] where Element.ID == ID
}

extension ViewModel where State.ViewState: CasePathable, Action: CasePathable {
    /// Enum state: projects the active case's payload, `nil` otherwise.
    public func scopeIfActive<P: ViewStateProjection, ChildAction>(
        state casePath: CaseKeyPath<State.ViewState, P>, action embed: CaseKeyPath<Action, ChildAction>
    ) -> ScopedViewModel<P.State, ChildAction>?

    /// Trapping form for use inside a matched `switch viewModel.viewState` case.
    public func scope<P: ViewStateProjection, ChildAction>(
        state casePath: CaseKeyPath<State.ViewState, P>, action embed: CaseKeyPath<Action, ChildAction>,
        fileID: StaticString = #fileID, line: UInt = #line
    ) -> ScopedViewModel<P.State, ChildAction>
}

extension ViewModel {
    /// Closure-mapped child action (no `CasePathable` requirement).
    public func scope<P: ViewStateProjection, ChildAction>(
        state keyPath: KeyPath<State.ViewState, P>, action embed: @escaping @MainActor (ChildAction) -> Action
    ) -> ScopedViewModel<P.State, ChildAction>
    /// Read-only child.
    public func scope<P: ViewStateProjection>(state keyPath: KeyPath<State.ViewState, P>) -> ScopedViewModel<P.State, Never>
}
```

The raw-enum `scopeIfActive(state: CaseKeyPath<State, Child>)` is removed: coexisting with the
projection overload makes `\.loaded` ambiguous, and raw state is not a view-facing type. Enum
scoping and bindings go through the `@CasePathable` mirror.

### 5.4 Bindings

Key paths are rooted at `State.ViewState`; `@Domain` members are rejected at the `$viewModel.x`
site with the unavailability message.

```swift
@dynamicMemberLookup
public struct _ViewModelBinding<F: FeatureProtocol, Value> {
    init(viewModel: ViewModel<F>, keyPath: KeyPath<F.State.ViewState, Value>)
    public subscript<Member>(dynamicMember keyPath: KeyPath<Value, Member>) -> _ViewModelBinding<F, Member>
    @MainActor public func sending(_ action: CaseKeyPath<F.Action, Value>) -> Binding<Value>
}

extension Bindable {
    public subscript<F: FeatureProtocol, Member>(dynamicMember keyPath: KeyPath<F.State.ViewState, Member>)
        -> _ViewModelBinding<F, Member> where Value == ViewModel<F>

    /// Enum case bindings go through the mirror's case paths, never the raw enum.
    public subscript<F: FeatureProtocol, CaseProjection>(
        dynamicMember keyPath: KeyPath<F.State.ViewState.AllCasePaths, AnyCasePath<F.State.ViewState, CaseProjection>>
    ) -> _ViewModelCaseBinding<F, CaseProjection> where Value == ViewModel<F>, F.State.ViewState: CasePathable
}
// `Binding` gets the same two subscripts. `_ViewModelCaseBinding` / `_ViewModelCaseMemberBinding`
// keep their shape (`sending(_:)`, `sending(_:default:)`) with `CaseProjection` replacing `Case`
// and extraction from `viewModel.viewState`.
```

### 5.5 `TestViewModel`

- `domainState` → `state`; `init(initialState:feature:)`.
- Equality is resolved as `feature.areStatesEqual ?? explicit parameter`; a missing equality is
  reported through `reportIssue` at `init` and assertions then fail with
  `TestFailure.missingStateEquality`. `init(initialState:feature:areStatesEqual:)` covers
  non-`Equatable` states and custom comparisons (the Todos example ignores generated IDs).
- Everything else (buffering, `receive`, exhaustivity, `TestEventTask`) is unchanged.

### 5.6 Unchanged

`Interactor` composition (`Interact`, `When`, `Merge`, `Debounce`, …), `Emission`, `DynamicState`
(effects read raw state), `EventTask`, `Internal/Execution/*`, `ObservationStateRegistrar`,
`ObservableStateID`. `Interactors.When` keeps operating on raw `WritableKeyPath<State, Child>` and
`CaseKeyPath<State, Child>`.

## 6. Observation guarantees

These are the behaviours the test suite asserts (all verified against the real registrar with the
§5.2 commit path):

| Scenario | Guarantee |
|---|---|
| Leaf change / unrelated leaf / equal value assigned | fires / silent / silent (per-member `Equatable` gating; `State: Equatable` not required) |
| `state.badge.count += 1`, directly or via `When`'s `&state[keyPath: \.badge]` | only `badge.count` observers fire; `badge.label`, `title`, root silent |
| Wholesale replacement `state = State(...)` with different content | root fires, every leaf re-reads |
| Wholesale replacement with equal content (`areStatesEqual` available) | nothing fires; registrars preserved |
| Content-equal child rebuild `state.badge = BadgeState(same)` | silent; child `_$id` preserved |
| Child rebuilt with different content | parent `\.badge` fires; observers that walked through `badge` re-read; root silent |
| Optional child `nil → value`; then `detail?.count += 1` | fires; then leaf-only |
| `rows[0].count += 1` / `rows.append` / `rows[id:]?.count += 1` | element-only / `rows` observers / element-only |
| Enum case switch / payload edit through `When`'s case path | root fires / leaf-only, root `_$id` unchanged |
| Observer re-reads synchronously during a mutation | no crash; reads the previous committed value |
| Coarse `viewModel.badge` read then `badge.count += 1` | silent (documented coarse-vs-fine rule) |

A child's `_$id` is bumped by its parent's `_modify` on in-place nested mutation; notifications stay
correct because `didModify` compares post-bump ids. No runtime logic gates on child ids; the root id
is the only coarse gate.

```swift
@FeatureState
struct CounterState: Equatable, Sendable {
    var count = 0
    @Domain var lastUpdatedAt: Date?
    var countText: String { "\(count)" }
    var lastUpdatedText: String { lastUpdatedAt.map { RelativeDateTimeFormatter().localizedString(for: $0, relativeTo: .now) } ?? "Never" }
}

@Interactor<CounterState, CounterAction>
struct CounterInteractor: Sendable {
    var body: some InteractorOf<Self> {
        Interact { state, action in
            switch action {
            case .task: return .perform { [counterClient] in .hydrated(try await counterClient.fetch()) }
            case .hydrated(let model):
                state.count = model.count
                state.lastUpdatedAt = model.updatedAt
                return .none
            }
        }
    }
}

let viewModel = ViewModel(initialState: CounterState(), feature: Feature(interactor: CounterInteractor()))
Text(viewModel.lastUpdatedText)          // re-renders when lastUpdatedAt changes
// viewModel.lastUpdatedAt               // error: 'lastUpdatedAt' is @Domain state and is not visible to views
```

Derived values that were cached by a reducer become computed properties (recomputed per read) or
stored visible properties the interactor keeps in sync.

## 10. Limitations

- Generic state types are unsupported (nested protocols cannot live in generic types).
- Methods and members declared in extensions of the state are not part of `ViewState`. View-side helpers belong in `extension FooState.ViewState { ... }` (where `_state` is reachable within the module).
- Same-module code can read `viewModel.viewState._state`; the underscore is the convention, `@_spi(Lattice)` the cross-module guard.
- `Sendable` on `ViewState` follows the state's inheritance clause only; conformances added in extensions elsewhere need a manual `extension FooState.ViewState: Sendable {}`.
- `ForEach` over `Array`-backed scopes re-finds elements by id per read (O(n)); use `IdentifiedArrayOf` for O(1).
- Compile cost ≈ 8 ms per `@FeatureState` type including plugin spawn.
- Known Swift 6.4 compiler bug: a source file that holds a `@FeatureState` enum together with other macro-annotated declarations (other `@FeatureState` types, `@CasePathable` enums, `@Observable` classes, `@Interactor` types, …) can crash the compiler (segfault in `TypeCheckPrimaryFileRequest`, apparently from type-checking the extensions that the attached macros on the generated `ViewState` declarations synthesize while the compiler iterates them), so declare each `@FeatureState` enum, `@CasePathable` or not, in its own file with no other macro-annotated declaration; files whose `@FeatureState` types are all structs are not affected (repro in §11).
